# 🔄 Day 6 — Loops That Never Stop (Unless You Tell Them To)

A lighter, later session today, but a good one — learned two of Python's core loop types.

## 🎯 What I learned
**While loops** and **for loops**.

I already understood the general concept of loops going in, but today brought a discovery I hadn't really noticed before: **`while` loops can run forever** if you let them, while **`for` loops are naturally limited** — they run through a fixed range or sequence and then stop on their own.

## 🧠 A concept that clicked
Learned how to intentionally create an **infinite while loop**, and more importantly, why you'd want to control one carefully — since without a proper exit condition, it really will just keep going forever.

## 💪 Applying it — the exercises

**While loop exercise:**
A program that keeps asking the user to enter their name, and won't stop asking until they actually type something in.

**For loop exercises:**
Practiced several small for-loop programs together in one file to get comfortable with the syntax and range-based logic.

**For loop project — New Year Countdown:**
A countdown program that counts down from 10 to 0 (10, 9, 8...), pausing for one second between each number — a fun, satisfying way to apply for loops to something real.
