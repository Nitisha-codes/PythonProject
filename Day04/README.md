# ✂️ Day 4 — Indexing vs. Slicing (They Are NOT the Same)

A smooth, easy-going day today — power stayed on the whole time, Git behaved, and I got through the full session without interruption. Nice change of pace after Day 3.

## 🎯 What I learned
Today's topic: **string slicing**, and along with it, **indexing** — two ways of pulling characters out of a string that I originally assumed were basically the same thing. Also got a start on **if statements**.

They are not. The brackets, colons, and commas each change the meaning completely, and once I actually started writing the code myself, the difference became obvious.

## 💭 My take on when to use which
This is just my personal preference at this stage, but here's how I've started thinking about it:
- **Indexing** → when I'm working with user input, since it feels more direct and precise for picking out specific characters
- **Slicing** → when solving a general problem that doesn't depend on user input, since it feels more reliable for grabbing chunks of a string at once
