# 🐣 Day 1 — The Very First Step

Today marks the official start of my cybersecurity journey — and every journey starts somewhere small. Today, it started with **variables**.

## 🎯 What I learned
- How to declare variables in Python (turns out, no `int`, `let`, or `var` keyword needed — Python just *knows*)
- The core data types: `int`, `float`, `str`, `bool`
- How `print()` works and how to display different variables together

## 🧠 A concept that clicked
Coming from C, I expected to declare a variable's type upfront. In Python, you just... don't. You write `age = 17` and Python figures out it's an integer on its own. Small thing, but it already feels like a different way of thinking.

## 🐛 A moment I got stuck
Honestly, the Python itself went smoothly — no real struggle there. The real learning curve today was **GitHub itself**. First time using it, and getting the hang of repos, commits, and pushing felt like a whole skill of its own, separate from the coding.
