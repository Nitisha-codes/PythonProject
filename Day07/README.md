## 🎯 What I learned
**Nested loops** — loops inside loops, and how they let you control two dimensions at once (like rows and columns) instead of just one.

## 💪 Applying it — the exercise
Built a program that draws a **four-sided polygon** (a square/rectangle shape) using a symbol of the user's choice. The program asks the user for three things:
- How many rows they want
- How many columns they want
- What symbol they want the shape made of

Then uses nested loops to print the shape accordingly. A satisfying, visual way to actually see nested loops working — each outer loop iteration building a row, each inner loop iteration filling in that row's columns.
